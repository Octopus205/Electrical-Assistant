# Electrical Assistant | مساعد مهندس الكهرباء

تطبيق Android مبني باستخدام **Kotlin** و **Jetpack Compose**، ويضم حاسبات كهربائية، محلل دوائر، مكتبة قوانين ورموز، اختبارات، حفظ المشروعات وتصدير تقارير PDF، ومساعد Gemini اختياري.

## بناء نسخة الاختبار

يعمل GitHub Actions عند تحديث ملف المشروع المضغوط أو سكربت الإصلاحات، ويمكن تشغيله يدوياً من **Actions → Electrical Assistant - Debug APK → Run workflow**.

بعد نجاح الاختبارات والبناء، افتح أحدث تشغيل ثم نزّل:
**Artifacts → Electrical-Assistant-debug-apk**

ملف APK نسخة Debug للاختبار، وليس إصدار Release. لا يتم إنشاء Release تلقائياً.

## الإصلاحات المضافة في عملية البناء

- التحقق من صحة المدخلات في حاسبات الكابلات وهبوط الجهد والمحركات وتصحيح معامل القدرة.
- منع اعتبار أكبر مقطع في جدول تقريبي آمناً تلقائياً إذا تجاوز الحمل سعة الجدول أو لم يتحقق حد هبوط الجهد.
- توضيح أن قيم سعة الكابلات تقريبية وتتغير حسب طريقة التمديد والحرارة والتجميع والكود المحلي.
- عرض سعة المكثفات لكل وجه في توصيلي Star وDelta بصورة منفصلة.
- تحسين التعامل مع أخطاء Gemini والمهل والحصة والردود الفارغة.
- إعادة بناء PDF متعدد الصفحات مع التفاف النص واتجاه عربي أفضل ومشاركة URI أكثر توافقاً.
- تشغيل اختبارات Gradle قبل بناء APK.

## Gemini API

المساعد الذكي يحتاج مفتاح Gemini صالحاً. لا تضع المفتاح في Git أو في APK منشور؛ أي مفتاح مضمن داخل التطبيق يمكن استخراجه من ملف APK. لهذا لا يتم تضمين مفتاح في بناء GitHub العام، وستظهر رسالة توضح أن الميزة غير مهيأة حتى إعداد طريقة آمنة للمفتاح.

مرجع إعداد Gemini: https://ai.google.dev/gemini-api/docs

## تنبيه هندسي

نتائج الحاسبات تعليمية/تقديرية وليست اعتماداً تصميمياً. يجب التحقق من بيانات المصنع، ظروف التركيب، تيار القصر، الحماية، التوافقيات، والمعايير المحلية بواسطة مهندس مختص قبل التنفيذ.
